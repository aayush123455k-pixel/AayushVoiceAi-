# Aayush Voice AI — Android App

## Setup Steps (Android Studio)
1. Unzip `AayushVoiceAI_Android.zip` and open the folder in **Android Studio**.
2. Wait for Gradle Sync to finish.
3. Connect your Android phone (USB Debugging ON) or build APK (`Build > Build Bundle(s) / APK(s) > Build APK(s)`).
4. Install APK on your phone and grant Microphone, Contacts, Phone, and SMS permissions.

## Supported Voice Commands (Hindi / Hinglish / English)
- **Call**: "Sintu Sir ko call karo" / "Call 8210922041"
- **WhatsApp / SMS**: "Sintu Sir ko WhatsApp message bhejo Hello" / "SMS Sintu Sir Class 5 PM hai"
- **Play Video**: "Play NEET Physics video" / "YouTube par Arijit Singh chalao"
- **Time**: "Time kya hua hai"
